# 📊 Sales Performance & Analytics Dashboard

An interactive, professional-grade Excel Sales Dashboard built to analyze multi-channel retail and corporate sales data. This dashboard provides deep insights into revenue trends, product performance, regional sales distribution, and customer behavior using advanced Excel features including Pivot Tables, Pivot Charts, and Interactive Slicers.

---

## 🚀 Key Features & Dashboard Components

* **KPI Summary Cards:** High-level metrics tracking **Total Revenue**, **Total Orders**, **Quantity Sold**, and **Average Order Value (AOV)**.
* **Interactive Slicers:** Dynamic filtering capabilities by:
  * Product Category (Accessories, Computers, Monitors, Networking, Office Supplies, Storage)
  * Customer Type (New vs. Returning)
  * Sales Channel (Corporate Sales, Marketplace, Online, Retail Store)
  * Region (Central, East, North, South, West)
  * Date, Month, Quarter, and Years Timelines
* **Visual Analytics & Charts:**
  * **Revenue by Month (Line Chart):** Tracks monthly revenue progression and trends over time.
  * **Top 5 Products by Revenue (Bar Chart):** Highlights the best-performing products (e.g., Ultrawide Monitor, Portable Monitor).
  * **Revenue by Region (Column Chart):** Compares performance across different geographical regions.
  * **Revenue by Product Category (Column Chart):** Breaks down earnings across hardware and accessory categories.
  * **Revenue by Sales Channel (Pie Chart):** Visualizes sales distribution proportions across online and retail channels.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data organization, cleaning, and custom number formatting.
* **Pivot Tables & Pivot Charts:** Dynamic data aggregation and visualization.
* **Excel Slicers:** For real-time, interactive dashboard filtering.
