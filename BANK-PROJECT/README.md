# 🏦 Bank Loan Default Analysis – Interactive Excel Dashboard

An interactive loan-portfolio dashboard built entirely in **Microsoft Excel**
using PivotTables, PivotCharts, Slicers and advanced formatting —
no Power BI, no add-ins.

## ⭐ STAR Method

### 📌 Situation
A bank processes thousands of loan applications and needs a quick view of
portfolio health — volume, funded amount, and which segments carry higher
default risk.

### 🎯 Task
Transform a raw loan-level dataset (255K+ records, 18 fields) into a
one-page interactive executive dashboard in Excel that answers:
- How big is the portfolio? (KPIs)
- Which segments (purpose / education / employment) drive applications & defaults?
- How do filters (term, purpose, employment, education) change the picture?

### ⚙️ Action
- **Data prep:** raw data converted to Excel Table; helper columns added
  (Employment-Length bins, Good/Bad Loan flag); blank rows cleaned
- **KPIs:** 6 card-style metrics via PivotTables + GETPIVOTDATA links, styled with icons
- **Visuals:** 11 PivotCharts — line, column, bar & doughnut
  (applications, amounts, default rates, home ownership, good vs bad split)
- **Interactivity:** 4 slicers connected to ALL pivots via Report Connections
- **Readability:** custom number formats (K / M / %), data labels,
  axis titles, sorting

### 📈 Result
- One-page report that updates instantly with slicers
- Key findings:
  - Default rate ≈ **11.6%**, avg interest ≈ **13.5%**, avg DTI ≈ **50%**
  - Good vs Bad loans ≈ **88% / 12%**
  - Home-purpose loans carry the highest avg interest rate (~19%)
  - Mortgage ownership split almost 50/50

## 🧰 Tools & Skills
Excel Tables • PivotTables • PivotCharts • Slicers • GETPIVOTDATA •
Custom Number Formats • SVG Icons • Dashboard Design • KPI Definition

1. Download the `.xlsx` and open it (Enable Editing)
2. Play with the slicers (Education / Term / Employment Type / Purpose)
3. Every KPI and chart updates live
