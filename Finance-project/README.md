📊 Interactive Financial Dashboard in Microsoft Excel
A fully interactive Financial Dashboard built from scratch using Microsoft Excel. This project is designed to analyze financial data, track key performance metrics (KPIs), and uncover critical business insights through dynamic visualizations and slicers.

🚀 Project Overview
This dashboard helps in monitoring sales, revenue, profit distribution, and product performance dynamically. It utilizes advanced Excel features like Pivot Tables, interactive Slicers, and customized charts to present data clearly for quick decision-making.

📈 Key Insights Uncovered
Top Markets: Mexico and the USA lead in total revenue generation.

Leading Product: 'Paseo' stands out as the most profitable product line based on profit distribution.

Core Segment: The Government sector drives the highest volume of units sold and overall revenue.

🛠️ Dashboard Features & Components
Interactive Slicers: Real-time filtering capability by Business Segments and Months to drill down into specific data points seamlessly.

Visualizations & Charts:

Revenue by Country (Bar Chart)

Profit by Products (Doughnut Chart)

Revenue by Segments (Horizontal Bar Chart)

Units Sold by Products (Bar Chart)

Dynamic Interactivity: Fully connected Pivot Tables and charts controlled via interactive filter connections.

💻 Tools & Technologies Used
Microsoft Excel: Pivot Tables, Pivot Charts, Slicers, Data Formatting, and Layout Design.

Data Visualization Principles: Clean color palettes, structured grid alignment, and executive card styling.

📂 How to Use / Run
Download the .xlsx file from this repository.

Open the file in Microsoft Excel (recommended version: Excel 2016 or later).

Use the interactive Slicers on the right side of the dashboard to filter data dynamically by month or segment.
