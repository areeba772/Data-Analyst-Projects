# Contributing to Data Analyst Projects Portfolio

Thank you for your interest in improving this portfolio and contributing new project ideas or improvements.

## How to Contribute

### 1. Report Issues
- Open an issue if you find a bug, typo, or broken link
- Include a clear description and expected outcome

### 2. Suggest Improvements
- Share enhancements for the README, project documentation, or design
- Use GitHub Issues for feature suggestions

### 3. Submit Pull Requests
1. Fork the repository
2. Create a branch for your feature or fix
3. Commit your changes clearly and professionally
4. Push to your fork
5. Open a Pull Request with a concise explanation

## Commit Style
Use clear and descriptive commit messages such as:
- `Add: new dashboard project`
- `Fix: broken portfolio links`
- `Docs: improve README formatting`
- `Refactor: clean project structure`

## Code and Documentation Standards
- Keep documentation clear and professional
- Avoid committing secrets, tokens, or sensitive information
- Maintain readable formatting and consistent structure
- Respect existing repository organization
